# LinguaQuest

**A full-stack language-learning app for English & Japanese, built from scratch as a solo engineering project.**

LinguaQuest turns daily language study into a small, gamified habit loop — vocabulary, spaced-repetition flashcards, quizzes, and progress tracking — for English and Japanese learners.

> This project is also a personal challenge: build a real, usable product end-to-end (frontend, backend, database, auth, deployment) while learning full-stack engineering hands-on.

---

## What it does

- **Vocabulary** — browse, search, and filter English/Japanese words by level and topic.
- **Flashcards & Spaced Review** — review due cards daily with a simple Again/Hard/Good/Easy scheduler.
- **Quizzes** — multiple-choice and recall questions that score your accuracy.
- **Progress Dashboard** — XP, streaks, daily goals, and achievements to keep learning consistent.
- **Japanese Basics** — Hiragana/Katakana trainer, beginner vocabulary, and a sentence builder for simple grammar patterns.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, TypeScript, Vite |
| Backend | Node.js, Express, TypeScript |
| Database | PostgreSQL, Prisma ORM |
| Auth | JWT-based authentication |
| Validation | Zod |

## Why this project

> "I built LinguaQuest because I wanted to solve my own language-learning problem while improving my full-stack engineering skills."

It's intentionally scoped as a small, well-engineered product rather than a large AI-tutor or social platform — the goal is a working tool that gets used every day, not a feature checklist.
